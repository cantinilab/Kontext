# kontext

**kontext** is a Python package for microenvironment-aware analysis of spatial and single-cell transcriptomics data.  
It provides tools for spatial domains identification, ligand-receptor scoring and niche analysis.

---

## Installation

### Requirements

- Python **>= 3.12**
- A working C/C++ compiler is recommended for `numba` / `scanpy` dependencies.

### From PyPI 

```bash
pip install kontext
```

### From github 

```bash
pip install git+https://github.com/YOUR_USERNAME/kontext.git
```
### Local installation

```bash
# from the kontext directory
